# Aplicación Ovina (Nombre pendiente)

- `api/` — Backend FastAPI (Render + Neon)
- `android/` — App Android (Kotlin, MVVM)
- `docs/` — Documentación

## Flujo de trabajo
1. Crea tu rama desde main: `feature/HU-XX-descripcion-corta`
2. Commits con el prefijo de la historia: `HU-XX: mensaje`
3. Abre un Pull Request hacia main y pide revisión
4. Se fusiona solo con 1 aprobación
